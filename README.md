## Agent tooling

- **[llm-wiki-scaffold](https://github.com/DavidChen-006/llm-wiki-scaffold)** — reusable scaffold for a self-specializing LLM wiki: ingest-time synthesis, filesystem-as-retrieval, two-layer validation, human-gated schema evolution.
- **[clank-research](https://github.com/DavidChen-006/clank-research)** — a coding-agent fork with a deterministic 3-layer `/research` workflow extension.
- **[flowchart-skill](https://github.com/DavidChen-006/flowchart-skill)** — derives a completeness-checked decision table first, then renders Mermaid + PNG.
- **[flutter-design](https://github.com/DavidChen-006/flutter-design)** — a Flutter design-system workbench: preview components, storyboard screens, walk the flow. Built to be edited by an agent.
- **[cleanmap](https://github.com/DavidChen-006/cleanmap)** — CLI that strips clutter from an image and returns the main subject.

## Hackathons

- **SIQUR** — 1st Place, Startup Track @ Catapult 2026. 3D world-model pipeline pairing exterior Gaussian-splat reconstruction with interior mesh rendering, a cross-camera motion reconstruction engine, and an ILP-based optimal camera placement solver.
- **[Squid](https://github.com/DavidChen-006/Squid)** — General Track Winner and Best Use of Solana @ HackINDY 2026. Text a purchase request over iMessage; an agent searches, validates against your constraints, and checks out. Evidence bundles anchored to Solana via SHA-256 Merkle roots.
- **[OpenPay](https://github.com/DavidChen-006/OpenPay)** — payments experiment built around agent-driven flows.

## Research & graphics

- **Semiconductor Digital Twin** (Birk Nanotechnology Center) — digital twin of a wafer for the cleanroom's Plasma-Therm, with an MLP regression model estimating etch depth from machine parameters across 500+ trials.
- **INDOT Driving Simulator** — real-time physics-based driving sim with multi-agent traffic, built from civil-engineering intersection blueprints.
- **VR Lab** (under Dr. Mousas) — VR interaction system simulating autonomous avatar behaviors; Python pipelines turning Qualtrics and Unity logs into analyzable HCI datasets.
- **[relearning-llms](https://github.com/DavidChen-006/relearning-llms)** — reverse-learning practice: deconstructing MoE + sparse attention architectures from the top down.
